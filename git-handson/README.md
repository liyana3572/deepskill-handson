# Git Hands-On Labs

1. **First commit** — init tracking, stage, commit, push
2. **.gitignore** — excluding `.log` files and a `log/` folder from tracking
3. **Branching & merging** — creating `GitNewBranch`, committing on it, merging into main
4. **Conflict resolution** — deliberately diverging `hello.xml` on two branches and resolving the conflict
5. **Clean up & push** — confirming clean state, pulling, pushing

The commit history in this folder (visible via `git log`) reflects all of the above, including the merge commit and the conflict-resolution commit.
